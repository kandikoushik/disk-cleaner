AI Agent & MCP Automation Ready

Built for AI assistants (ChatGPT, Claude, Gemini, Antigravity, Cursor) with official llms.txt standard and MCP tools.

📄 llms.txt Standard

Standardized Machine Context file at /llms.txt allowing AI web search engines and agents to discover Disk Cleaner features.

🔌 Model Context Protocol

Full MCP Server schema specification in MCP_GUIDE.md defining tools for disk scanning and dry-run cleanup.

⚙️ Machine JSON CLI

Execute --scan --json to receive structured JSON target definitions, sizes, and risk levels without parsing raw text.
